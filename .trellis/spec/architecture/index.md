# Cross-Layer Architecture Specifications

These specs define contracts that no single backend or frontend guide owns.
They are implementation guidance, not thinking checklists.

| Spec | Covers |
|---|---|
| [System Boundaries and Module Loading](./system-boundaries.md) | Repository applications, first-party modules, plugins, menus, and ownership |
| [HTTP and Realtime Contracts](./http-and-realtime-contracts.md) | REST envelopes, frontend adapters, authentication, SSE, and WebSocket protocols |
| [Code Generation and Routing](./code-generation-and-routing.md) | Generator inputs, templates, output paths, menus, permissions, and failure behavior |

Source is authoritative where README or comments disagree. Known mismatches are
recorded explicitly so future changes do not copy them as preferred patterns.
